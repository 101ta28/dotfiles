# 説明文の緩急

章・記事の該当箇所を前後の段落と続けて読み、どこを読み返したか、どこで説明が進まなくなったかを手掛かりに直す。手順書や短い回答に、読み物としての演出を持ち込まない。

| 読者がつまずく箇所 | 編集の判断 |
|---|---|
| 条件と挿入句が重なり、何を述べているか見失う | 条件を対象の主張に近づけ、独立して読める補足を別の文に移す。 |
| 短文が続き、事実同士の関係を補わないと読めない | 同じ観測や操作を扱う文をつなぐ。資料から分かる順序・因果・対比を示す。 |
| 評価だけが続き、同じ結論に戻ってくる | 重複を削り、資料にある事例・数値・コードを、それが支える主張の近くに置く。 |
| 箇条書きを追っても説明の流れが見えない | 並列の項目は残し、ある結果が次の判断につながる箇所は段落にする。 |

読者が概念を知っていれば、その概念から具体例へ進める。初めて扱う話題なら、実際の疑問や観測から始めてもよい。読み手を引き付けるために感情や事実を足したり、必要な答えを引き延ばしたりしない。

たとえば「同じ入力で試しました。キャッシュなしでは800 msでした。ありでは200 msでした。計測はそれぞれ1回でした。」は、「同じ入力で試すと、キャッシュなしでは800 ms、ありでは200 msでした。計測はそれぞれ1回です。」とまとめられる。条件と測定値を一緒に読み取れ、次の文で結果の限界が分かる。

修正した段落を通して読み、文の分割や結合で否定・条件・留保のかかる範囲が動いていないかを確かめる。自然に読める文末や語り口は保つ。文長、読点数、漢字率は修正箇所を探す手掛かりに使い、一律の目標にしない。
